Archive

Archive commands by task

This page is for power users and administrators who use the Archive from the terminal. Each table row gives a task, a command line that does it, and a link to that command's full entry. The commands come with the Archive and are there once it is installed; The Archive says what it adds, and Commands by task has core's commands and how to read the tables.

EiN runs most of the analysis by itself after an upload; the commands here are for looking things up, changing them by hand, and doing one thing again. Albums, People and faces and the other guide pages show the same tasks in the web interface.

Search your pictures

search is core's command, and what it finds in pictures, people, places and labels comes from the Archive. Searching your pictures covers the same in the web interface.

Pictures, videos and recordings

Task Command Reference
Everything about one file media-details /archive/albums/christmas-2019/20191224_141841.jpg media-details
Its metadata as exiftool reads it exiftool <file> exiftool
Set when it was taken, as vaguely as you know file-set-time <file> 1968-07 --note 'Postmark on the back' file-set-time
Undo a date set by hand file-set-time --clear <file> file-set-time
Set where it was taken file-set-position <file> --lat=50.2632 --lng=-5.0510 file-set-position
Rotate or mirror it for good file-set-orientation --rotate cw <file> file-set-orientation
Write its description file-set-description --text 'Christmas morning' <file> file-set-description
Correct the text read from it file-set-text <file> --text 'Dear Peggy' file-set-text
Read its text again in another language file-set-text-language <file> en file-set-text-language
Correct what is said in a video or recording cat corrected.vtt | file-set-transcript <file> file-set-transcript
Say who took it file-set-photographer <file> /archive/people/helen-okafor file-set-photographer
The latest pictures taken latest 20 latest

A value that starts with a minus goes after an equals sign, as in --lng=-5.0510; on its own it would be read as another option. Only file-set-time can give a picture a vague date such as 1968 or 1968-07; the web interface's dialog sets full dates. Dates and places of pictures explains which date a picture gets.

To have EiN look at one file again, run the step with -f:

Task Command Reference
Read the text in a picture again read-text -f <file> read-text
Find the faces again (boxes drawn by hand stay) detect-faces -f <file> detect-faces
Transcribe a recording or video again transcribe-file -f <file> transcribe-file
Make thumbnails and renditions again regenerate --force <file or folder> regenerate

All four ask the media service, so they need it running. For many files at once, an administrator starts the pipelines instead: see Processing and pipelines.
