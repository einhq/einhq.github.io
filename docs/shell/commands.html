The shell and SSH

Commands by task

This page is for power users and administrators who know what they want to do and need the command for it. Each table row gives a task, a command line that does it, and a link to that command's full entry in the reference.

How to read the tables

  • Every command runs as you, with your permissions, in the terminal or over SSH. The examples use the demo archive's invented Wrenfield family: the album /archive/albums/christmas-2019, the person /archive/people/Peggy_Wrenfield, the account helen.
  • administrators only marks a command that anyone else is refused before it starts, with <name>: permission denied: only an administrator may run it. A member of the sudo group can type admin to act as the administrator in that terminal. Accounts and groups explains who that is.
  • The archive, assistant and media service commands come with their modules. Without the module, the shell answers error: command '<name>' not found. mod list shows what is installed.
  • A command of a family can be typed as two words: mod install is mod-install, and pipeline status is pipeline-status. The families are config, docs, group, mod, pipeline, pool, service, share and user, and with the archive also person and device. <family> --help, such as mod --help, lists its subcommands; typing mod alone answers mod: missing subcommand.
  • <command> --help prints a command's arguments, options and examples without running it. JSON_OUTPUT=1 in front of a command makes it answer in JSON; The shell language covers that and the rest of the syntax.
  • cd, pwd, jobs, kill and the other bash builtins have no reference entry. They are described in The shell language.

Files and nodes

The tree works like a file system: paths start at /, .. is the parent, and cd moves you around. Any node can have children, so cd into a photo works and ls shows what EiN learnt about it, such as exif, position, thumbnails and regions. The tree says what lives where.

rm deletes for good: it does not use the trash. Unix commands EiN does not have

EiN's commands are its own, so some familiar names are missing. Use these instead.

You may type Use instead
touch mkfile
vi, nano edit
less, more, man the terminal's scrollback, <command> --help, and the reference
realpath abspath
which type <name> or command -v <name>
passwd, useradd, usermod user-passwd, user-create, user-update; for groups, group-add-member
chgrp chown :<group> <path>
sudo, su admin or user-elevate, for members of sudo
getfacl, setfacl acl
tar, rsync, curl, wget, diff, tee none in EiN; unzip unpacks zip files, and scp copies over SSH

There is also no sh or bash command: a script is run by its path, or with source. The shell language explains scripts.

When a command is refused or missing

What you see Why What to do
error: command '<name>' not found No command of that name is on your PATH: a typing error, or a module that is not installed Check the name with docs find <words>; see mod list
<name>: permission denied: only an administrator may run it The command is for administrators Ask an administrator, or type admin if you are in the sudo group
<name>: permission denied, you must be a member of group 'ssh' ssh, scp and ssh-copy-id need the ssh group An administrator adds you with group-add-member ssh <you>; sign in again
<name>: sign in first You are not signed in, and visitors may not browse login <username>
rm: cannot remove '<path>': Node not empty The node has children rm -r <path> deletes it with them; trash put <path> keeps it recoverable
edit: not a terminal edit needs a terminal, which ssh host 'command' does not give Log in with ssh first, or use the terminal panel
